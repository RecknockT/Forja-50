# RTX 3090 · perfil inicial de desarrollo

El soporte se limita al nombre exacto NVIDIA GeForce RTX 3090 de escritorio, con 24 GB de VRAM y 32 GB de RAM instalados. La 3090 Ti no se incorpora por similitud de nombre. Forja utiliza una sola GPU seleccionada; no combina su memoria con otras tarjetas.

## Motor y archivo de modelo

KVMem 0.18.0 ofrece un [paquete Windows para RTX 30 / sm86](https://github.com/kvmem/kvmem/releases/tag/v0.18.0). El paquete requiere controlador compatible con CUDA 13.2 y Visual C++ 2015–2022 x64; incluye dependencias CUDA. No requiere compilar CUDA en la PC del usuario. El autor todavía marca pendiente la validación de inferencia de esta versión en hardware RTX 30.

- ZIP: `kvmem-v0.18.0-ninfer-windows-rtx30-sm86.zip`.
- Tamaño publicado: 1.018.841.562 bytes.
- SHA-256: `1f4bab96cde5f5a80eb7d46f074cca5f8a9294121ed53570b0c422a05eb6e301`.
- Destino separado: `runtime/ninfer-rtx30/kvmem-v0.18.0-ninfer-windows-rtx30-sm86/workers/ninfer/ninfer-kvmem-server.exe`.
- Modelo Swift IQ3_S de 12.790.639.360 bytes, el mismo artefacto fijado para KVMem en Forja. No se utiliza el modelo de Todd ni el motor compilado para sm120a.

## Aprovechamiento de los 24 GB

| Ajuste | 128K inicial | 64K | 32K |
| --- | --- | --- | --- |
| Contexto lógico | 131.072 | 65.536 | 32.768 |
| Historial seleccionado en GPU | 98.304 | 49.152 | 24.576 |
| Reserva de generación en GPU | 16.384 | 16.384 | 8.192 |
| Caché de historial en RAM | 8.192 MiB | 4.096 MiB | 2.048 MiB |
| Prefill | 512 | 512 | 512 |
| Umbral inicial de VRAM libre | 20.000 MiB | 17.000 MiB | 13.000 MiB |

Se mantienen KV rk8v4, GDN FP16, MTP-3, ngram 15/mínimo 12, razonamiento 2.048 tokens, salida máxima 8.192, una petición/sesión y visión apagada. El historial seleccionado más la reserva crecen de 32K en el perfil RTX 50 de compatibilidad a 112K en el perfil 3090 de 128K.

Los valores y umbrales son decisiones iniciales conservadoras del producto, no mediciones de consumo ni garantía de que cualquier escritorio pueda cargarlos. KVMem recupera parte del historial desde RAM: 128K lógico no significa atención completa sobre los 128K en GPU. Mantener el mismo modelo evita una segunda descarga de pesos al cambiar entre tarjetas en modo KVMem.

## Comportamiento y validación

En una instalación nueva se detecta la 3090, se selecciona KVMem, se exige aceptar sus licencias y se muestra el perfil. El motor RTX 50 queda deshabilitado. Los binarios de arquitecturas diferentes se almacenan por separado. La preparación y el arranque comprueban el perfil; no se considera preparada una 3090 por encontrar solamente el binario sm120a.

Las personalizaciones KVMem existentes se conservan. Restaurar la recomendada recupera 128K y sus presupuestos. La lista de contextos y la ventana avanzada se adaptan a la placa. Cambiar de contexto desde un presupuesto estándar ajusta también la ventana GPU; un presupuesto personalizado incompatible se rechaza con explicación.

Pendiente: carga real, verificación de memoria dedicada/compartida, conversación larga, uso de herramientas y tareas Git en una RTX 3090 física. Las pruebas automáticas con hardware simulado verifican selección, parámetros, persistencia y controles de interfaz; no acreditan inferencia.
